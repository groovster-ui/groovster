# MCM Atomic library classes

Costume ornament is the default when `data-fidelity-band` is absent. Opt down with `whisper` or `standard` (`default` / `signature` are deprecated aliases).

Hero mode is **light** (Formica day, cream `#F3E9D2`). Dark is **Googie night** (`#10223A`).

## Hero (`.ew-hero__stage` required)

| Class | Role |
| --- | --- |
| `.ew-hero` | Hero shell |
| `.ew-hero__stage` | **Required** costume backdrop host |
| `.ew-hero__twotone` | Diagonal two-tone split ('57 Chevy) |
| `.ew-hero__starbursts` | 5–9 varied 8-point starbursts |
| `.ew-hero__arch` | Parabolic LAX Theme Building arch |
| `.ew-orbit` | Atom orbit centerpiece (3 ellipses + nucleus) |
| `.ew-hero__content` | Script / title / subtitle / CTA stack |
| `.ew-script` | Yellowtail Googie script accent |
| `.ew-hero__title` | League Spartan geometric caps |
| `.ew-hero__cta` | CTA row |
| `.ew-badge-new` | Starburst “NEW!” badge |

## Components

Cards get a turquoise header band, 2px charcoal outline, TV radius, kidney corner blobs, and a crisp offset shadow. Primary buttons are coral pills with a starburst; secondary is turquoise outline. Fields are white with charcoal borders, turquoise caps labels, and mustard focus.
