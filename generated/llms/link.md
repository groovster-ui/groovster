## Link (`ew-link`)

Text link with era underline/voice.

HTML:
```html
<a class="ew-link" href="/pricing">View pricing</a>
```

CSS: @groovster/css/link.css + @groovster/css/eras/<era>.css
Variants: variant=default|subtle|nav(default:default)
Sizes: sm|md|lg (default md)
ARIA: link (native a)
Do: Use href.
Don't: Don't use buttons styled as links for navigation.
